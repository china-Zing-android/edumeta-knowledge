## SECTION 1 — Undergraduate education

### 1.1 Architecture
Portland State is a public urban R2 research university in downtown Portland, OR. Founded 1946. ~21,000 students (largest in Oregon). Strong in social work, urban studies, sustainability, engineering, liberal arts. Has accelerated online programs.

## SECTION 3 — Application requirements & deadlines

### 3.1 Undergraduate (from pdx.edu/admissions)

| 项 | 要求 |
|---|---|
| Application | PSU Application or Common App |
| Application fee | $50 (waiver available) |
| SAT/ACT | Test-optional (Oregon State System) |
| HS GPA | 2.0+ recommended |
| English (international) | TOEFL 71 iBT / IELTS 6.0 / PTE 48 / Duolingo 100 |
| Fall priority deadline | April 1 |
| Fall final deadline | Rolling (subject to space) |
| Winter deadline | November 1 |
| Spring deadline | February 1 |

### 3.2 Graduate (from pdx.edu/graduate-studies)

| 项 | 要求 |
|---|---|
| Application | Grad Studies Application |
| Application fee | $65 domestic / $75 international |
| English (international) | TOEFL 80 iBT / IELTS 6.5 / PTE 60 / Duolingo 110 |
| GRE/GMAT | Varies by program (some require, some don't) |
| Fall priority deadline | April 1 |
| Winter priority deadline | October 1 |
| Spring priority deadline | January 1 |
