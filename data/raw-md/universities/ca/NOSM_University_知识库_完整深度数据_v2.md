## Section 1：本科教育 — 全量项目列表

### 1.1 本科医学教育 (Undergraduate Medical Education - UME)

NOSM University 提供唯一一个本科水平（准本科后）项目——医学博士（MD）项目。

#### MD 项目详情

| 项目名称 | 学位 | 学制 | 校区 | 语言 | 认证 |
|---------|------|------|------|------|------|
| Doctor of Medicine (MD) Program | MD | 4年 | Sudbury + Thunder Bay | 英语 | CACMS 完全认证 |

**特色说明：**
- 采用分布式社区参与教学模式（Distributed, Community-Engaged Learning Model）
- 教学范围覆盖安大略省北部数千公里，90+个社区合作
- 2026-2027学年提供92个席位，计划未来扩展至108个
- 临床培训在社区医院、健康中心、家庭诊所等多元化环境进行

**入学要求：**
- 加拿大公民或永久居民
- 安大略省普通居民（95%席位保留给安省居民）
- 4年制本科学位（任何专业）
- 最低GPA 3.0/4.0（竞争性录取，录取平均GPA约3.79/4.0）
- 不要求MCAT成绩
- 不要求TOEFL成绩
- 无必修课程前提，但推荐文理均衡的本科教育
- 通过安大略医学院申请服务 (OMSAS) 提交申请

**申请流程：**
- OMSAS 申请开放：7月中旬
- 申请截止：10月第一周
- 面试邀请：1月
- 面试日期：2月底至3月初（MMI + Panel面试）
- 录取通知：5月第二个星期二

**录取数据（2025年入学班级）：**
- 申请人数：2,516
- 面试人数：317
- 录取人数：88
- 平均GPA：3.79/4.0
- 平均年龄：24岁

**招生通道 (Admission Streams)：**
1. **一般招生通道 (General Admission Stream)** — 所有申请者默认通道
2. **原住民招生通道 (Indigenous Admission Stream)**
3. **法语招生通道 (Francophone Admission Stream)**
4. **黑人招生通道 (Black Admission Stream)**
5. **军事医学培训项目通道 (Military Medical Training Program - MMTP Stream)** — 当前暂停

**申请评估权重：**
- 面试前评分（GPA + 背景评分，各50%）：约32%
- 面试评分：约68%
- 完整档案审核：含保密评估表（CAF）、自传摘要（ABS）和学术历史

## Section 3：申请要求与截止日期

### 3.1 MD 项目申请要求

**基本资格：**
- ✅ 加拿大公民或永久居民
- ✅ 安大略省普通居民（95%席位保留要求，2025年7月1日起生效）
- ✅ 4年制本科学位（任何专业）
- ❌ 不需要 MCAT 成绩
- ❌ 不需要 TOEFL 成绩
- ❌ 无必修课程前提

**GPA 要求：**
- 最低 GPA：3.0/4.0
- GPA 计算包含所有本科课程（含重修、暑期/春季/远程课程）
- 研究生课程成绩不计入 GPA 计算
- 按 OMSAS 本科分级系统转换表进行成绩转换

**申请材料：**
1. 通过 OMSAS 提交在线申请
2. 官方成绩单（Transcripts）
3. 保密评估表 (Confidential Assessment Forms - CAFs) — 3份
4. 自传摘要 (Autobiographical Sketch - ABS)
5. 证明公民身份/永久居民身份的文件（录取后提交）

### 3.2 关键日期

| 事件 | 日期 |
|------|------|
| OMSAS 申请开放 | 7月中旬 |
| 申请截止 | 10月第一周 |
| 面试邀请通知 | 1月 |
| MMI 面试 | 2月26日 |
| Panel 面试 | 2月28日 - 3月1日 |
| 录取通知 | 5月第二个星期二 |
| 学费押金截止 | 6月4日（$1,000） |
| 第一笔学费分期截止 | 8月15日 |
| 第二笔学费分期截止 | 12月15日 |
| 最终成绩单提交截止 | 6月30日 |

### 3.3 语言能力要求

- NOSM University 不要求 TOEFL 考试
- 申请材料须以英文提交（以下除外）：
  - 法语招生通道的推荐信和论文须以法语提交
  - 保密评估表（CAF）可由推荐人以法语提交
- NOSM University 保留拒绝英文能力不足申请者的权利
- 所有课程以英语授课

### 7.1 NOSM University 关键特征总结

| 维度 | 特征 |
|------|------|
| **定位** | 加拿大第一所独立医科大学 |

| **社会问责** | 对社会文化多样性的责任，包括原住民和法语社区 |

| **国际学生** | MD项目仅限加拿大公民/永久居民；MMS项目接受国际学生（2027年起） |
| **班级规模** | ~88-92人（计划扩展至108人） |
| **年度学费范围** | MD：$24,768-$24,868；MMS国内全日制：$13,048；MMS国际：$35,130 |

### 7.2 与加拿大其他医学院对比

NOSM University 是加拿大最具特色的医学院之一，其独特性体现在：
1. **唯一独立医科大学** — 区别于加拿大其他隶属于综合性大学的医学院
2. **分布最广的教学网络** — 跨越安大略省北部全境
3. **最低的入学门槛要求** — 不要求MCAT、无必修课程前提
4. **最强的地区导向** — 95%席位保留给安省居民，88%录取学生来自安省北部
5. **最低的学费** — MD项目学费约$24,767/年，显著低于加拿大其他医学院（通常$25,000-$30,000+）
6. **社会责任使命** — 专门针对安省北部医疗需求设计的教育模式
