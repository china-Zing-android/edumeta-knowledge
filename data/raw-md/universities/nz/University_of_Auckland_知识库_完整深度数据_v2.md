## 五、录取要求

### 本科录取要求

#### 新西兰高中生 (NCEA)

| 条件 | 要求 |
|------|------|
| **新西兰大学入学资格 (UE)** | NCEA Level 3 需满足: 3门认可科目各14学分 (Level 3); 英语/毛利语 10学分 (Level 2+, 阅读写作各5学分); 数学 10学分 (Level 1+); 最低总计 60学分 (Level 3) + 20学分 (Level 2+) |
| **专业入学排名分数** | 各专业有不同 Rank Score 要求 (Guaranteed Entry Score) |

| 课程体系 | 最低要求 | 备注 |

| **International Baccalaureate (IB)** | 通常要求 24–36+ 分 | 视专业不同，高竞争专业要求更高 |
| **美国高中 (AP/SAT)** | 参考具体专业要求 | |

### 研究生录取要求

#### 硕士课程

| 类型 | 最低要求 |
|------|---------|
| **授课型硕士 (Taught Master's)** | 相关学科的学士学位 (通常要求 GPA 4.0–5.0+/9.0 或 equivalent) |
| **研究型硕士 (Research Master's)** | 相关学科荣誉学士或四年制学士，有研究经历 |
| **入学英语要求** | IELTS 6.5 (各单项不低于 6.0) 或同等水平 |

#### 博士课程

| 条件 | 要求 |
|------|------|

| **研究计划** | 需提交 Research Proposal |
| **导师确认** | 需先联系导师并获得确认 |

#### 其他研究生证书/文凭

- 研究生证书 (PGCert): 学士学位，通常 60学分
