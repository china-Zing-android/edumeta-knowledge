## 八、录取要求 (Entry Requirements)

### 8.1 本科录取要求 (Bachelor's Degrees)

#### 国际学历要求 (按国家)

| 国家/地区 | 要求 |
|-----------|------|
| **Australia (澳大利亚)** | Year 12 + ATAR score ≥ 69.6 或同等 |
| **Bangladesh (孟加拉国)** | Higher School Certificate (HSC) 完成 |
| **China (中国)** | Gao Kao (高考) 成绩 + 高中毕业证; 或 Foundation 课程 |
| **India (印度)** | Standard XII 完成，特定分数要求 |
| **Indonesia (印尼)** | SMA 毕业 + 特定分数 |
| **Malaysia (马来西亚)** | STPM / A-Levels / UEC 特定成绩 |
| **Philippines (菲律宾)** | 高中毕业 + 特定要求 |
| **United Arab Emirates (阿联酋)** | 特定要求 |
| **Vietnam (越南)** | 高中毕业 + 特定要求 |
| **International Baccalaureate (IB)** | 满足大学入学要求 |
| **Cambridge International Examinations (CIE)** | 满足大学入学要求 |
| **NCEA Level 3** | 新西兰本地学历，满足 University Entrance (UE) |

#### 通用本科录取途径
- **University Entrance (UE)**: NCEA Level 3 / CIE / IB 成绩
- **Pathway 途径**: 通过文凭课程完成后进入学士学位第二年
- **其他高中学历**: 按国家具体评估

### 8.2 英语语言要求 — 本科

| 考试 | 最低要求 |
|------|---------|
| **IELTS (Academic)** | **总分 6.0**, 单项不低于 5.5 |
| **TOEFL iBT** | **总分 80**, 阅读≥15, 听力≥15, 口语≥18, 写作≥20 |
| **PTE (Academic)** | **总分 50**, 单项不低于 42 |
| **NZCEL** | NZCEL Level 4 (Academic Endorsement) |
| **C1 Advanced (Cambridge)** | 总分 ≥ 169, 单项不低于 162 |
| **LanguageCert International ESOL** | C1 Expert IESOL (LRWS) 通过 |
| **English New Zealand Pathway** | Level 2 (单项不低于 Level 1) |
| **Trinity ISE** | ISE II, 单项不低于 Distinction |
| **Duolingo English Test (DET)** | **105** |
| **AUT Academic English (AUT AE)** | B overall, 单项 C+ 或更高 |

> 注: 部分专业 (如护理、教育、法律等) 有更高的英语要求。

### 8.3 研究生录取要求

| 层次 | 要求 |
|------|------|
| **Graduate Certificate / Graduate Diploma** | 通常需已完成本科学位 |
| **Postgraduate Certificate / Diploma** | 相关本科学位 |
| **Master's (授课型)** | 相关学士学位, 部分要求工作经验 |

| **PhD (博士)** | 研究型硕士学位或荣誉学士学位 (一等/二等上); 需提交研究计划 |
