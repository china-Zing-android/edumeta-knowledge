## SECTION 3 — Application requirements & deadlines

### 3.1 Undergraduate Entry Requirements

#### 通用入学要求

| 考试体系 | 典型要求 | 说明 |
|---------|---------|------|
| **UCAS Tariff** | 112-128 points | 因课程而异 |
| **A-Level** | BBC-ABB | 因课程而异 |
| **IB** | 28-31 | 因课程而异 |
| **BTEC Extended Diploma** | DMM-DDM | 因课程而异 |
| **Access to HE** | 102-118 tariff points | Merit level |
| **T Level** | Merit (120 tariff) | 部分课程接受 |
| **GCSE** | English + Maths grade 4/C | 通用要求 |
| **Scottish Highers** | AABC-AAAB | 因课程而异 |

#### BSc (Hons) Computer Science 示例

| 考试体系 | BSc要求 | MSci要求 |
|---------|---------|---------|
| **UCAS Tariff** | 112-128 | 128 |
| **A-Level** | BBC-ABB | ABB |
| **IB** | 28-31 | 31 |
| **BTEC Extended Diploma** | DMM-DDM | DDD |

- **UCAS Code**: I100 (BSc) / I101 (Foundation Year)
- **Institution Code**: B50
- **Required Subjects**: All subjects considered

### 3.2 Postgraduate Entry Requirements

#### 通用要求

- **硕士学位课程**: 需持有相关学科的2:2或以上学士学位
- **MBA**: 通常需要工作经验

#### MSc Computer Science 示例

- **学历要求**: 相关学科的2:2学士学位
- **相关学科**: Computer Science, Computing, Cyber Security, Artificial Intelligence, Software Engineering
- **其他接受学科**: Mathematics, Physics, Engineering（需有IT工作经验）
- **学制**: 1年全日制（9月入学）/ 16个月全日制（1月入学）

### 3.3 English Language Requirements

#### 通用要求

| 学历层次 | IELTS (Academic) 要求 |
|---------|---------------------|
| **本科 (Bachelor's)** | 总分6.0，各单项不低于5.5 |
| **硕士 (Master's)** | 总分6.0，各单项不低于5.5 |
| **研究型学位 (Research)** | 总分6.5，各单项不低于5.5 |

#### 接受的英语考试

| 考试类型 | 说明 |
|---------|------|
| **IELTS (Academic)** | 最常用，UKVI认可 |
| **LanguageCert** | UKVI认可 |
| **Pearson Test of English (Academic)** | UKVI认可 |
| **Kaplan Test of English (KTE)** | BU申请人可享25%折扣（£88.50） |
| **Oxford International ELLT** | 使用BU折扣码BU10可享10%折扣 |

#### 免考英语条件

- 来自UKVI认可的英语国家的国民
- 在英语国家完成等同于英国学士学位的学历
- 持有GCSE/IGCSE/A Level英语成绩（英国学校）

### 3.4 Application Deadlines

#### 本科 (UG)

- **UCAS申请**: 通常1月25日截止（牛津剑桥和医学10月15日）
- **Clearing**: 7月-9月开放
- **2026年入学**: Clearing已开放，可在线申请或致电+44 (0)1202 966777
- **2027年入学**: 通过UCAS申请

#### 研究生 (PGT)

- **滚动录取**: 大多数课程全年接受申请
- **建议申请时间**: 尽早申请，特别是热门课程
- **2026年入学**: 9月和1月入学均可申请
- **2027年入学**: 申请已开放

### 3.5 January Intake (1月入学)

部分课程提供1月入学选项，主要面向国际学生：

- **BSc Computer Science**: 1月入学专为国际学生设计
  - 第一学期：1月至5月
  - 第二学期（压缩）：6月至7月
  - 第二年和第三年：与常规学年同步
