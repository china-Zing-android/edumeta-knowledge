### 校训

**拉丁语**: *Ad Astra* — "奔向星辰"
**爱尔兰语**: *Cothrom na Féinne* — "公平与正义"

### 使命与特色

UCD 是爱尔兰规模最大、最具国际化的大学，在 QS 世界大学排名中位列第100位（2027年），进入全球前1%高等教育机构行列。学校以研究密集型教学为特色，在兽医科学、食品科学、计算机科学、商业管理、法律和医学等领域处于领先地位。UCD 是 National University of Ireland (NUI) 的成员机构，也是 Universitas 21、CESAER 等国际大学联盟成员。

### 历史沿革

- **1854年**：由 John Henry Newman（后封圣）创办为 Catholic University of Ireland
- **1883年**：更名为 University College，由耶稣会管理
- **1908年**：成为 National University of Ireland 的成员学院，正式更名为 University College Dublin
- **1909年**：Royal University 解散，UCD 作为 NUI 成员大学运作
- **1960年代起**：逐步从都柏林市中心搬迁至 Belfield 校区
- **1997年**：Universities Act 确立 UCD 作为 NUI 内独立大学的地位
- **2023年12月**：发射爱尔兰首颗卫星 EIRSAT-1（由 UCD 研发）

## 5. 本科招生数据

### 5.1 申请系统

- **EU/EEA/UK 申请人**：通过 **CAO (Central Applications Office)** — cao.ie 统一申请
- **非欧盟国际学生**：通过 **UCD Apply** 直接申请 — ucd.ie/apply/
- CAO 代码前缀：**DN**（如 DN001 为 UCD 医学）

### 5.2 申请要求

#### CAO 入学要求（EU申请人）

| 要求 | 内容 |
|------|------|
| 基础要求 | 爱尔兰 Leaving Certificate（或等效国际学历） |
| 英语要求 | EU/EEA 国家免英语考试（非英语母语国家除外） |
| 最低准入标准 | 至少2门 Higher Level 科目+4门其他科目（含英语和数学） |
| 特定课程要求 | 不同课程有特定的科目和成绩要求 |
| 限制性课程（Restricted） | 医学、兽医、物理治疗等需额外评估（面试/笔试/作品集） |

#### CAO Points 录取体系

爱尔兰大学本科录取基于 **CAO Points** 点数系统，由爱尔兰 Leaving Certificate 成绩转换而来。UCD 热门课程近年点数参考：

| 课程方向 | 近年点数范围（参考） |
|---------|-------------------|
| 医学（Graduate Entry） | 竞争激烈 |
| 兽医学 | 600+ |
| 物理治疗 | 550+ |
| 法律 | 500-550 |
| 商学 | 450-500 |
| 计算机科学 | 450-500 |
| 工程 | 400-500 |
| 理学 | 350-450 |
| 人文 | 300-400 |

> **注意**：每年点数根据申请人数和成绩分布变动，以上为参考范围。

#### 国际学生入学要求

| 学历体系 | 要求 |
|---------|------|
| 中国高考 | 需完成高中教育+高考成绩+预科（IFP）或凭高考成绩申请（部分课程） |
| A-Level | 通常要求 ABB-A*AA（依课程而异） |
| IB | 通常要求 30-38分（依课程而异） |
| 美高/AP | 通常要求 SAT/ACT + 高中毕业证 |

### 7.1 本科费用（年度参考）

#### EU/EEA 本科生

| 费用项目 | 金额（2025/26参考） |
|---------|-------------------|
| **学费（Free Fees Initiative）** | 由爱尔兰政府承担（符合条件者） |
| **学生贡献费（Student Contribution Fee）** | ~€3,000/年 |
| **学生会费（Student Levy）** | ~€250/年 |

> **适用条件**：首次攻读学士学位、欧盟/EEA/瑞士国籍、在爱尔兰/欧盟地区居住满3年。

#### 非EU国际本科生

| 学科方向 | 年度学费范围（2025/26参考） |
|---------|--------------------------|
| 人文与社会科学 | €15,000–€20,000 |
| 商学 | €18,000–€22,000 |
| 工程与建筑 | €20,000–€26,000 |
| 理学 | €20,000–€25,000 |
| 医学（临床阶段） | €45,000–€55,000 |
| 兽医学 | €30,000–€40,000 |
| 护理与健康科学 | €18,000–€22,000 |

### 7.2 研究生费用（年度参考）

#### 授课型研究生（Non-EU）

| 学科方向 | 年度学费范围（2025/26参考） |
|---------|--------------------------|
| 人文与社会科学 | €15,000–€20,000 |
| 商学（MSc） | €18,000–€25,000 |
| MBA（Smurfit全日制） | €35,000–€45,000 |
| 工程与计算机 | €20,000–€27,000 |
| 理学 | €18,000–€25,000 |
| 法律 | €18,000–€22,000 |
| 医学相关 | €22,000–€40,000 |

#### 研究型研究生（Non-EU）

| 学位 | 年度学费范围 |
|------|------------|
| PhD（非临床） | €14,000–€20,000 |
| MSc by Research | €14,000–€18,000 |

> **EU研究生学费**通常为Non-EU费用的30-50%。

### 7.3 其他费用

| 费用项目 | 金额 |
|---------|------|
| 注册费/申请费 | €50–€100 |
| 学生中心服务费（Student Levy） | ~€250/年 |
| 住宿费（校内） | €6,000–€12,000/年 |
| 生活费（含住宿、餐饮等） | €12,000–€15,000/年 |
