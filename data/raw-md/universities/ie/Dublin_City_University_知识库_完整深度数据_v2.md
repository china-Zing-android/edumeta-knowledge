## 0. 学校概览

| 项目 | 内容 |
|------|------|
| **学校名称** | Dublin City University (DCU) — 都柏林城市大学 |
| **学校类型** | 公立大学 |
| **建校年份** | 1975年（1989年获大学地位） |
| **校长** | Prof. Dáire Keogh |
| **学生总数** | ~19,000人 |
| **国际学生** | 来自124个国家 |
| **校区分布** | 3个校区：Glasnevin（主校区）、St Patrick's（Drumcondra）、All Hallows（Drumcondra） |
| **地理位置** | Glasnevin, Dublin 9, Ireland |
| **官网** | https://www.dcu.ie/ |
| **学校特色** | 爱尔兰首个将工作实习（INTRA）融入本科课程的大学；超过80%的课程提供工作嵌入式学习机会 |
| **注册慈善号** | RCN 20013653 |

### 使命与特色

DCU是爱尔兰一所年轻、富有雄心和创新精神的大学，使命为"transform lives and societies"（改变生活和社会）。它是爱尔兰第一所将工作实习（INTRA - INtegrated TRAining）嵌入所有本科课程的大学。

### 三大校区

1. **Glasnevin Campus**（主校区）：包含John and Aileen O'Reilly图书馆（400个工作站、1,200个座位、18个协作室）、餐厅、剧场和会议中心（The Helix）、托儿所、体育中心
2. **St Patrick's Campus**（Drumcondra）
3. **All Hallows Campus**（Drumcondra）

## 5. 本科招生数据

### 5.1 入学途径

| 申请人类别 | 申请途径 |
|-----------|---------|
| **爱尔兰/欧盟申请人** | 通过 CAO (Central Applications Office) 系统申请 |
| **非欧盟国际学生** | 通过 DCU 直接在线申请（Registry - Applications from outside the EU） |
| **成熟学生（23岁以上）** | 通过 CAO 申请，无需标准学术要求，评估生活/工作经验 |
| **转学生** | 通过 Registry 申请内部转学 |

### 5.2 学术入学要求

#### 爱尔兰 Leaving Certificate
- 一般要求：6个科目，其中至少2个H5等级及以上
- 英语：O6/H7 以上
- 数学：多数专业要求特定等级
- 具体专业要求因专业而异

#### UK A-Levels
- 一般要求：至少2-3门A-Level达到C级以上
- 加GCSE：英语、数学和另一门语言

#### 国际文凭 (IB)
- 接受IB Diploma

#### 中国学生
- 完成高中并参加高考，成绩优秀者可考虑直接进入本科
- 或通过 DCU International Foundation Programme

#### QQI FET (PLC)
- Level 5/6 证书可用于申请许多专业

#### HEAR (Higher Education Access Route)
- 为经济弱势学生提供的高等教育入学通道

### 5.3 英语语言要求（非母语申请人）

> **政策说明**: 英语证书须在 DCU 课程开始前 **2年内** 获得。成绩必须在一个考试单次中取得。

#### 本科英语最低要求

| 考试类型 | 最低要求 |
|---------|---------|
| **Irish Leaving Certificate English** | O6/H7 |
| **GCE A-Level English Language** | Grade D |
| **GCSE** | Grade C |
| **IELTS Academic** | **总分6.5，单项不低于6.0** |
| **TOEFL iBT** | **总分92**，或最低总分4.5且每部分不低于4.5（取决于考试版本）；**不接受TOEFL Home Edition** |
| **TOEFL (computer-based)** | 237 |
| **TOEFL (paper-based)** | 580 |
| **Cambridge Certificate** | 180分（Cambridge English Scale），每项技能不低于169；2027年入学将变为176+ |
| **PTE Academic** | **总分63，单项不低于59** |
| **Duolingo** | **总分120，每个单项（口语、写作、阅读、听力）不低于110**；需要提供验证链接 |
| **ETAPP** | C1或以上 |
| **IELCA Academic** | 总分35，每项不低于33（2027年入学） |
| **Language Cert (ESOL)** | B2 Communicator High Pass，每项不低于33 |
| **Language Cert Academic** | 总分70，每项不低于65 |
| **Oxford English Test** | 总分140，每项不低于125 |
| **Trinity ISE** | ISE III，每项技能至少merit |

#### 例外情况
在英语为官方语言的国家完成英语授课教育的学生，可提交相关证明替代标准化考试成绩。

#### 重要提示
- 个别专业的英语要求可能高于通用标准
- 所有成绩必须同一个考试单次获得
- 不接受 TOEFL Home Edition

### 5.4 国际学生申请流程

1. **在线申请**: 通过 DCU Registry 网站提交申请
2. **所需材料**:
   - 学历证明及成绩单（英文翻译件）
   - 英语语言能力证明
   - 护照复印件
   - 个人陈述（部分专业）
   - 推荐信（部分专业）
3. **审理**: DCU 审理后发放录取通知
4. **接受录取**: 缴纳押金确认位置
5. **签证申请**: 持录取通知书申请爱尔兰学生签证

## 6. 研究生招生数据

### 6.1 入学要求

#### 学术要求
- **授课型硕士**: 通常要求本科学位（2:2或以上，或GPA 2.6+/4.0 根据QS数据）
- **研究型硕士/博士**: 要求相关学科本科学位，部分要求硕士学位

#### 英语语言要求
- **通用要求**: 与本科相同（见5.3节）
- **QS数据**: 硕士入学要求 GPA 2.6+，雅思 6.5+，托福 92+，PTE 63+，Duolingo 120+

### 6.2 申请流程

| 申请类型 | 申请方式 |
|---------|---------|
| **PhD/研究型硕士** | 通过 DCU Graduate Studies Office 申请 |
| **授课型硕士** | 通过 DCU Registry 在线申请系统 |
| **欧盟申请人** | 通过 Registry - EU applications |
| **非欧盟申请人** | 通过 Registry - Non-EU applications |

#### 申请材料
- 学历证书和成绩单
- 英语语言能力证明
- 个人陈述/目的陈述
- 2封推荐信
- 简历/CV
- 研究计划（研究型课程）
- 护照复印件

## 7. 学费与财务

### 7.1 学费概况

> **注意**: 以下数据基于2026-2027学年公开信息。具体费用以DCU Fees Office正式发布的Fee Schedule为准。
> **学费每年都会增长（subject to annual increase）**。

#### 本科国际学生学费（2026-2027学年）
- 非欧盟本科生学费因专业而异，大致范围为：**€15,500 - €25,000/年**

- 非欧盟研究生学费因专业而异，大致范围为 **€17,000 - €25,000/年**

#### 欧盟学生学费
- 欧盟本科生：享受爱尔兰政府"Free Fees Initiative"补贴，仅需缴纳学生贡献费（Student Contribution Fee）约 €3,000/年
